# Amr Ahmed Abdellatif — Video Editor Portfolio

A static portfolio website. Open `index.html` locally or publish the repository with GitHub Pages.

## Add your videos
1. Put your video files inside the `videos/` folder.
2. Open `index.html` and edit the `WORKS` array near the bottom.
3. Replace the sample titles, descriptions, dates, and filenames with your own.
4. Make sure each `file` path matches the actual file name, e.g. `videos/project-one.mp4`.

## Publish with GitHub Pages
1. Create a new public repository on GitHub (for example `amr-portfolio`).
2. Upload `index.html`, `README.md`, and the `videos` folder.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then save.
6. GitHub will provide the website URL after deployment.

Large video files may exceed GitHub's regular file-size limits. For large projects, use Git LFS or host videos on a video platform and embed/link them instead.
